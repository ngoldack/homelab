You are a senior software engineer. Write a complete, correct Python implementation of
an LRU cache that is thread-safe for concurrent reads and writes. Requirements:

1. API: class LRUCache with __init__(self, capacity: int), get(self, key) that returns
   the value or -1 if absent, and put(self, key, value) that inserts or updates and
   evicts the least-recently-used entry when at capacity.
2. Both get and put must count as "usage" for LRU recency.
3. Thread safety: concurrent access from multiple threads must never corrupt
   internal state. Prefer a lock-based approach; add type hints and a brief docstring
   for each method.
4. Performance: get and put must be O(1) average case. Use an ordered-dict or a
   hash map + doubly-linked list; if you use a linked list, implement it explicitly
   with Node objects.
5. Handle these edge cases: capacity less than 1 should raise ValueError; a key that
   is evicted and later re-inserted must work; get on a missing key returns -1.
6. Include a main block demonstrating usage with assertions, plus a short docstring
   at the top of the module explaining the design and the expected average-time
   complexity of each operation.

Make the code production-quality: clear names, no dead code, and correct behavior.
Explain briefly in comments where concurrency could go wrong without the lock.
